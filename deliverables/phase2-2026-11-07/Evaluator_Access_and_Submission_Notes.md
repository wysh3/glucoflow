## Access instructions field

No manual credentials needed. Open the link, select **Explore the clinic**, then **Create workspace**. These actions sign into a shared synthetic demonstration account and create a fresh simulation with three fictional DKA encounters. Please use fictional information only.

Start in Chat. Ask: “Which collected specimens are still awaiting lab receipt?” Open the returned source evidence. Worklist shows operational tasks and human approvals. Encounters provides the documented context and a reviewed handover action. The workspace menu contains Demo controls for simulating hospital/laboratory events and Workflow learning for approved operational procedures. New chat starts a separate saved simulation. Patient view is a separate account with patient permissions.

Hospital and laboratory feeds are simulated. This is workflow assistance, not diagnosis, prescribing or clinical decision support. If Hermes is unavailable, the interface offers an explicitly labelled deterministic helper; its responses are not live AI.
