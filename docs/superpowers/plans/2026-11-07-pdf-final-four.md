# Final four PDF demo workflows

User authorizes direct implementation, followed by GPT-6.1 Terra simulated usage review. Source: original 26-page blueprint, bounded delegation contract and sections 7, 8, 10. Preserve the existing architecture and compact canvas; no new permanent navigation rail destinations.

## Design

1. One approved shift-monitoring group captures a fixed set of explicitly selected/assigned encounters, named rule, sources, recipients and absolute expiry. Per-order evidence checks stay separate inside the group. Human approval starts it; edits require approval again. Pause/stop/expiry are auditable. Never notify externally or infer clinical urgency. Current sources remain synthetic. Existing single-order tasks remain supported and are not silently duplicated or appropriated.
2. Nurse My Shift surfaces named work/exceptions with soft acknowledgement that never closes source-backed work. Lab queue separates expected, received, processing-unverified and validated states using actual available source events; no guessed processing. Handover drafts are editable before export and retain exact-version receipt by a named authorized receiving person. Receipt never transfers clinical responsibility.
3. A compact static synthetic supervisor view groups illustrative waiting work and next owners by unit; no ranking of people, no automated reallocation, no claimed live staffing optimization.
4. Appointment preview becomes reachable from the workspace. It remains a logistics-only local preview with no sending or scheduling; changing any detail revokes previous approval.
