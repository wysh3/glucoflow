Networking notes:

* the app reaches the host API through `adb reverse tcp:8787 tcp:8787` on an emulator
  (the macOS firewall blocked the emulator's NAT route to `10.0.2.2` in this environment);
* `apps/client/android/app/src/main/res/xml/network_security_config.xml` permits cleartext
  HTTP **only** for `10.0.2.2`, `127.0.0.1` and `localhost`; everything else must be HTTPS;
* the API must list the WebView origin `https://localhost` in `ALLOWED_ORIGINS`. It is in
  the default list, and the failure mode without it is a `Failed to fetch` on every call.

## Reproduce

```bash
cd app
pnpm android:keystore
export JAVA_HOME="$PWD/.local/toolchain/jdk-21.0.12.1+1/Contents/Home"
pnpm android:apk
adb install -r apps/client/android/app/build/outputs/apk/release/app-release.apk
adb reverse tcp:8787 tcp:8787
adb shell am start -n in.sutra.demo/.MainActivity
```
