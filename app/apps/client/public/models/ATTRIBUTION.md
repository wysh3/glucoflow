# Anatomy model attribution

The interactive 3D body in the Body map is adapted from the HuBMAP Human Reference Atlas female reference organ set.

- Kristen Browne and Heidi Schlehlein, Human Reference Atlas / HuBMAP, 3D Reference Organ Set for Female, v1.10, 2026.
- Built on the Visible Human Dataset of the U.S. National Library of Medicine: Spitzer, V. M. and Whitlock, D. G., The Anatomical Record 253(2), 2002.
- Source: https://humanatlas.io/3d-reference-library
- Original GLB: https://cdn.humanatlas.io/digital-objects/ref-organ/united-female/v1.10/assets/3d-vh-f-united.glb
- License: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/

Adaptation for this product: the source scene was reduced to the body surface plus the heart, kidneys, pancreas and eyes, then Draco-compressed for the web. The viewer colours those structures for a follow-up coverage map. This is an educational reference body, not a patient scan and not a clinical device.

The body surface is shown translucent so the recorded follow-up areas can be seen. No diagnosis, risk score or treatment recommendation is derived from the model.
